# School of Accidental Photography

Gallery + submission page for AccPho (Suite 315, Strange Bird Immersive).

- `index.html` – the whole site. Set `SCRIPT_URL` near the top of its script to the Google Apps Script web-app URL.
- `apps-script/Code.gs` – the Google Apps Script that stores submissions in Google Drive
  (My Drive › SBI › AccPho › Pending / Approved). Move a photo to Approved to put it in the gallery.
